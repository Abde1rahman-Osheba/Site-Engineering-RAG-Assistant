# LLM generation (Part C.7) - local, self-hosted only (no Anthropic/OpenAI)
#
# Default backend: GGUF quantization via llama-cpp-python, loading straight
# from the Hugging Face Hub (see config.py's GGUF_REPO/GGUF_FILENAME). Plain
# `pip install llama-cpp-python` gives you a CPU-only build (fine, just
# slower). For GPU acceleration on Windows + an NVIDIA GPU, install the
# prebuilt CUDA wheel instead:
#   pip install "llama-cpp-python==0.3.22" --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
# Pinned to 0.3.22 deliberately, NOT the latest (0.3.35 at time of writing):
# newer prebuilt CUDA wheels from this index compile in AVX-512 codegen,
# which crashes with an illegal-instruction error (WinError 0xc000001d) on
# Intel 12th/13th/14th-gen "hybrid" CPUs (P+E cores) - those chips have
# AVX-512 fused off, and llama.cpp's CPU-backend init/dispatch doesn't
# guard against it on this build - confirmed by testing both variants
# directly against this project's model. 0.3.22 is the newest version at
# this cu124 index confirmed to compile without AVX-512. If you're not on
# an Intel hybrid CPU (or hit no crash), the latest version is fine too -
# drop the `==0.3.22` pin.
llama-cpp-python>=0.3.0
